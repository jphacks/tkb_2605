# プロフィール表示と編集プレビュー

投稿のアイコン・名前から/profile/{user_id}へ移動する。投稿APIのIDと名前をナビゲーション状態で渡し、URLのIDと一致するときだけ名前を表示する。直接開いた場合は、ユーザー別投稿のGET結果から名前を取得する。ユーザー情報APIがまだないため、未取得の自己紹介や画像を捏造せず準備中として示す。

ユーザー別投稿はGET /api/users/{user_id}/posts/?limit=20&offset=0。next_offsetによる追加取得・失敗時再試行・いいねを共通ApiTimelineで扱う。他人の投稿が混ざる応答は表示せずエラーにする。最新mainの投稿APIはまだ固定応答のため、対象ID以外は未接続として表示されることがある。

肩・首・胸の形はホームと共通のBodyFrame。関係は「マスメイトである／ない」の2状態のみで、フォロー・フォロワーや承認待ちは設けない。どちらか一方が「マスメイトになる」を押すと、その2人はマスメイトになり、ボタンは無効な「マスメイト」表示になる。解除操作は置かない。

関係APIが未実装のため、現在は2人のIDの順序によらない表示用ダミーとして保持する。同じタブで画面を移動して戻っても状態を維持し、別の相手の状態とは分離する。再読み込みで初期化され、実際の相手の端末や通知は変更しない。API接続時は片方の操作で関係を一度だけ保存し、どちらのユーザーから取得しても同じ成立状態を返す必要がある。

/profile/meは認証済みの実IDへ転送し、自分の投稿も実IDで取得する。/profile/me/editには登録名を読み取り専用で表示し、自己紹介（160文字まで）・アイコン色の表示編集を用意する。更新APIがないため、変更は同じタブのプロフィール・ホーム・サイドバーにのみ反映する。再読み込み・ログアウト・アカウント変更で破棄し、別ユーザーへ引き継がない。
