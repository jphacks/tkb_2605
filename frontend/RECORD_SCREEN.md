# 記録画面

Issue #22 に沿って、中央の種目名、重量・回数のセット行、追加・削除、別の種目／終了の導線を実装しています。

- 重量は初期値 0 kg、回数は空欄。セットは最低 1 つ残り、2 セット目以降を削除できます。
- Issue #14 のテーブル定義に合わせ、重量は 0 以上・小数第1位まで、回数は 1 以上の整数に制限します。
- 保存 API は未定義です。ユーザー確認に基づき、2 ボタンで端末内の下書きを保存して遷移します。サーバー保存や認証済みユーザーへの紐付けは行いません。
- 下書きは `workout.draft.v1:<URLエンコードしたworkoutId>` に保存します。別の種目の下書きを維持し、破損した既存データは上書きしません。保存が失敗すると入力を残して移動を止めます。
- 記録画面へのリンクには `state={{ exerciseName, returnTo: "exercises" }}` を渡します。おすすめからは `returnTo: "recommendations"` を渡し、「別の種目」で元の選択画面へ戻ります。
- 「終了」は既存の結果 URL へ遷移します。結果画面本体の実装はこの PR の対象外です。

検証: `npm run lint`、`npm run build`、`npm run test:record`。
